# Project Documentation (`/docs`)

Folder ini berisi dokumen spesifikasi produk dan rancangan arsitektur teknis proyek **Glow AI**. Struktur ini dibuat standar agar dapat dibaca dengan mudah oleh developer maupun AI Coding Assistant (Gemini, Claude, Cursor, Copilot, dll.).

## 📁 Struktur Folder

- **`docs/prd/`**: Berisi **PRD (Product Requirement Document)** yang mendeskripsikan visi produk, fitur, user flow, dan kriteria sukses.
- **`docs/rfc/`**: Berisi **RFC (Request for Comments)** yang mendeskripsikan rancangan teknis, arsitektur data, API, dan keputusan teknis proyek.

---

> **💡 Petunjuk untuk AI Coding Assistant:**
> Setiap kali memulai tugas baru atau menambah fitur, selalu periksa dokumen di folder `docs/prd/` dan `docs/rfc/` untuk memahami konteks bisnis serta keputusan teknis aplikasi ini.
